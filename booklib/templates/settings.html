🤖 Искусственный интеллект

ИИ используется для кнопки «📖 Краткое содержание» в карточке книги — он читает текст книги и делает саммари. Выберите движок ниже. По умолчанию — выключено.

🖥 Ollama (локальный ИИ, бесплатно)

1. Скачайте с ollama.com/download и установите.
2. Откройте командную строку и выполните: ollama pull llama3.1:8b (займёт 5–10 минут).
3. Убедитесь, что Ollama запущена (значок в трее).
4. Проверьте соединение кнопкой «Проверить» ниже.

☁ OpenAI (облако, по ключу)

Ключ берётся на platform.openai.com/api-keys. Стоимость саммари одной книги — примерно 1–3 цента (модель gpt-4o-mini).

☁ Anthropic Claude (облако, по ключу)

Ключ берётся на console.anthropic.com.

🎤 Голосовой ввод

Работает через встроенный модуль браузера. Звук уходит в Google/Microsoft для распознавания. Работает только в Chrome, Яндекс.Браузере, Edge. В Firefox — не поддерживается.

Статус в вашем браузере: проверяется...
  • 🎤 рядом с полем — нажмите, говорите. Пауза 3–5 секунд — авто-стоп.
  • Красная кнопка — идёт запись. Нажмите её ещё раз, чтобы остановить раньше.
  • Где есть микрофон: поиск в шапке, Название, Автор, Заметки в карточке.
  • Отдельная кнопка «🎤 Долгая голосовая заметка» — удобно диктовать абзацы.
